ÍHÍ Game Entry for Hydra

A faster, touch-friendly screen for entering live game data into IIHF Hydra. Version 1.4.2 · built 2026-10-13 20:23 UTC
New to it? Read the operator guide – á íslensku or in English, one printable page per role.
Practise first: the training site (æfingasvæði) has the same screens with sample games and a teacher that walks you through each task, in Icelandic or English. Nothing there goes to Hydra.
Just following a game? The Hydra watch only bookmark opens the same screen read-only: it shows what is entered in Hydra and refreshes every 20 seconds, but has no buttons that save anything.
How it works. You log in to Hydra as usual. The game entry screen then runs inside your logged-in Hydra page: everything is saved straight into Hydra (Orion and Gemini Light). Nothing goes anywhere else. You need a Hydra login with rights to the game.
Counting shots on a phone? One person per team, each on their own phone. Set up the Hydra shots bench bookmark below (iPhone: the iPad tab, Android: the Android tab), log in to Hydra on the phone, tap the bookmark, then pick the game and your team.

Option 1 — Userscripts app (recommended: works like an app icon)

  1. Install the free Userscripts app from the App Store, open it once and pick a folder for scripts.
  2. In Settings → Safari → Extensions, turn Userscripts on and allow it on ihi.hydra.iihf.com (or "All websites").
  3. In Safari, open hydra-ui.user.js, tap the Userscripts icon in the address bar and choose Install.
  4. Log in to Hydra, then open https://ihi.hydra.iihf.com/IIHF_Core/hydra-ui. Tap Share → Add to Home Screen for an icon. The shots bench is …/IIHF_Core/hydra-ui?mode=bench.

Option 2 — a bookmark (no app needed)

  1. Copy the bookmark code below (Copy button).
  2. In Safari, bookmark any page (Share → Add Bookmark), name it Hydra game entry, save it in Favourites.
  3. Edit that bookmark (Bookmarks → Edit), delete its address and paste the copied code.
  4. Log in to Hydra, then tap the bookmark. Do the same with the second code for the shots bench (on a phone you only need that one).

Chrome — a bookmark

  1. Copy the bookmark code below.
  2. In Chrome, bookmark any page (☆), then edit the bookmark: name Hydra game entry, paste the code as the URL.
  3. Log in to Hydra. To start: type Hydra game entry in the address bar and tap the bookmark in the suggestions.

Firefox — Tampermonkey (opens by itself)

  1. Install Firefox for Android, then the Tampermonkey add-on.
  2. Open hydra-ui.user.js and install it in Tampermonkey.
  3. Log in to Hydra and open https://ihi.hydra.iihf.com/IIHF_Core/hydra-ui (bench: add ?mode=bench).
Kiwi Browser is no longer maintained (discontinued January 2025), so it gets no security fixes. Please use Chrome or Firefox instead.

Chrome or Edge — the extension (adds a button to Hydra's menu)

  1. Download hydra-ui-extension.zip and unzip it.
  2. Open chrome://extensions (Edge: edge://extensions), switch on Developer mode, click Load unpacked and pick the unzipped folder.
  3. Log in to Hydra and click Open game entry ↗ at the top right of Hydra's menu.
  4. New version: download again, replace the folder, and press the reload icon on the extension.

…or the bookmark

Drag a button to the bookmarks bar, log in to Hydra and click it. Always loads the newest version.
